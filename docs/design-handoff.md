## 1. 이 사이트는 무엇인가요

- **이든카페**는 별무리마을 학생 협동조합 카페입니다. 이 사이트는 **빵 픽업 주문 사이트**입니다.
- **주 이용자는 연령대가 있는 마을 주민**입니다. 그래서 글자와 버튼은 크게, 흐름은 단순하게 유지합니다.
- **기능이 먼저, 꾸밈은 그다음**입니다. 예쁜 것보다 "처음 온 어르신이 헤매지 않고 주문할 수 있는가"가 판단 기준입니다.
- 온라인 주문은 **베이커리만** 됩니다(음료는 매장 전용, 안내만 표시).
- 운영 사이트: https://edencafewebsite.seyoung8219.workers.dev
- 저장소: https://github.com/seyoung9089/edencafewebsite

- shadcn/ui용 토큰(`--primary`, `--background` 등)도 같은 파일에 있고 위 색과 같은 값을 가리킵니다. `.dark` 블록은 남아 있지만 **다크 모드는 쓰지 않습니다.**
- 홈 첫 화면(히어로)은 사진이 없을 때 빵 색 그라데이션(`#E9C79A`, `#B9824F`, `#5A3B2A` 계열)을 씁니다 → `src/components/hero-section.tsx`.
- 알림 토스트는 `#2A211D` 바탕 → `src/routes/__root.tsx`.

### 2-2. 글꼴

- **제목(h1~h3)**: Noto Serif KR **300(얇은 명조)**, 자간 `-0.02em`.
- **본문·버튼**: Noto Sans KR 400/500/700.
- Google Fonts로 불러옵니다(`src/routes/__root.tsx`의 `links`).
- 한국어가 단어 중간에서 끊기지 않도록 `word-break: keep-all`이 전체에 걸려 있습니다(예: "휘낭\n시에" 방지). 지우지 마십시오.
- **작은 영문 소제목(`.eyebrow`)**: 0.8rem, 굵게, 자간 0.2em, 대문자, 초록색. 예: `VILLAGE PICKUP`, `STEP 1 · PICKUP DAY`.
  - 참고: 미병합 PR #14에는 이 영문 소제목을 한글("1단계 · 날짜")로 바꾸는 안이 들어 있습니다(6장 참고).

### 2-3. 모서리·그림자

- **네모에 가까운 모서리**: `--radius: 0.1875rem`(3px), 카드는 `rounded-card`(2px).
- 그림자 대신 **얇은 선**: `shadow-soft` = 1px `eden-line` 테두리. 떠 보이게 할 때만 `shadow-lift`.
- 둥근 알약 모양 버튼은 쓰지 않습니다(홈의 화살표 동그라미 아이콘만 예외).

### 2-4. 버튼 (`.btn`, `src/styles.css`)

| 클래스 | 모양 | 쓰는 곳 |
|---|---|---|
| `.btn` | 초록 바탕 + 흰 글자, hover 시 더 진한 초록 + 위로 4px | 주요 행동(주문하기 등) |
| `.btn.ivory` | 아이보리 바탕 + 갈색 글자 | 초록·갈색 띠 위의 버튼 |
| `.btn.ghost` | 투명 + 글자색 테두리 | 보조 행동 |

- **최소 높이 3.5rem(56px), 글자 1.05rem 굵게.** 어르신용이므로 **이보다 작게 만들지 않습니다.**
- 비활성 버튼은 반투명(opacity 0.5).

### 2-5. 레이아웃 규칙

- 좌우 여백은 `.pad` 클래스 하나로 통일(화면 폭에 따라 16px~96px).
- 헤더는 위에 고정(`fixed`), 홈에서만 투명하게 겹칩니다. 그래서 `scroll-padding-top: 84px`.
- 스크롤 등장 효과는 `.reveal`(`src/components/reveal.tsx`). "움직임 줄이기" 설정 사용자에겐 꺼집니다.
- 휴대폰 주문 화면에는 **아래 고정 주문 막대**가 있고, PC(`lg` 이상)에서는 오른쪽 **고정 요약 상자**(`aside sticky`)로 바뀝니다.

## 4. 사장님(세영 님)이 확정한 취향

- **아이보리 바탕 + 진한 갈색 글자 + 이든 초록 한 가지 포인트**, 얇은 명조 제목, 네모 버튼 (2026-10-31 전면 개편, PR #11).
- **차분하고 담백하게.** 학생 협동조합다운 정직한 느낌. 과한 장식·화려한 효과는 피합니다.
- **어르신용 큰 버튼·큰 글자 유지.**
- **날짜 고르기는 본문 흐름 안의 STEP 1**이어야 합니다(PR #21).
- **빵은 종류별로 묶고, 종류 순서는 사장님이 정한 순서**: 휘낭시에 → 쿠키 → 에그타르트 → 베이글 → 소금빵 → 치아바타. 종류 안에서는 이름순. 순서는 관리자에서 `menu_groups.sort_order`로 관리됩니다.
- **내 주문 카드는 사장님 손그림대로**(PR #18): 픽업 날짜가 가장 크게, 그다음 상태.
- **헤더 로고 자리는 'Eden cafe' 글자.**
- **문구 말투:** 고객 화면 안내 문구는 **격식체**('~입니다/~습니다', '~해 주시기 바랍니다')로 통일하기로 결정했습니다. 단, FAQ의 *질문*(고객 목소리)과 관리자 화면은 예외입니다. AI가 쓴 것처럼 딱딱하거나 과장된 표현은 피합니다.
  - ⚠️ 현재 `main`에는 '~요' 말투가 섞여 있습니다(예: 홈 "주문을 마치면 입금할 계좌와 금액이 바로 나와요."). 격식체 정리는 미병합 PR #14에 들어 있습니다.

## 6. 미해결 과제 (이어받으실 일)

1. **홈이 초록 일색이고, 버튼까지 같은 초록이라 구분이 안 된다**는 불만 — 가장 큰 숙제입니다.
   - 지금 홈에서 초록(`eden-accent`)이 '마을 픽업 주문' 면, PICKUP 띠, 버튼에 모두 쓰입니다. 초록이 **면(바탕)**과 **버튼**을 동시에 맡고 있어서 버튼이 눈에 띄지 않습니다.
   - 색 리뷰 문서에서 **A안(초록은 버튼에만 쓰고, 넓은 면은 아이보리/갈색/세이지로)**을 추천했고, B안도 함께 캡처해 두었습니다. 사장님이 "일단 아무것도 하지 말자"고 하셔서 **반영 보류 중**입니다. 진행 전에 사장님과 방향을 먼저 맞추십시오.
2. **PR #14 미병합** — https://github.com/seyoung9089/edencafewebsite/pull/14
   - 담긴 것: 홈 날짜 칸 클릭 시 그 날짜로 주문 화면 열기, 영문 소제목 → 한글, 11~12px 작은 글씨 키우기, 비활성 버튼을 회색 바탕+진한 글씨로, "준비 중"·"매장에서만 주문"을 버튼처럼 안 보이게, 고객 화면 격식체 정리, 휴대폰 주문 화면에서 위로 가기 버튼 숨김 등.
   - 2026-11-01 사장님 결정으로 보류. 이후 PR #18·#21과 **충돌**하므로 그대로 병합할 수 없고, 필요한 부분만 새 브랜치로 다시 옮겨야 합니다.
3. 작은 것들: 메뉴 사진이 아직 적어 홈 '오늘의 메뉴'가 1장만 보일 수 있음(가격 입력 전). 홈 히어로 실제 사진 미등록 시 그라데이션이 보임.

## 8. 코드에서 디자인을 바꾸는 방법

### 파일 위치 요약

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 색·글꼴·버튼·여백 공통 규칙 | `src/styles.css` |
| 웹폰트 불러오기 | `src/routes/__root.tsx` |
| 헤더 / 푸터 | `src/components/site-header.tsx`, `site-footer.tsx` |
| 홈 | `src/routes/index.tsx`, `src/components/hero-section.tsx` |
| 주문 화면 3종(마을·학부모·답례품) | `src/components/order-page.tsx` (한 파일을 함께 씀 — 한 곳을 바꾸면 세 화면이 같이 바뀝니다) |
| 날짜 선택 | `src/components/pickup-date-picker.tsx` |
| 내 주문 | `src/components/my-orders.tsx` |
| 기본 UI 부품(shadcn/ui) | `src/components/ui/*` |

- 스타일은 **Tailwind v4 클래스**를 컴포넌트에 직접 씁니다. 색은 `bg-eden-*`, `text-eden-*`, `border-eden-*` 토큰을 쓰고, `#3F5A4A` 같은 값을 직접 쓰지 않는 것을 권합니다.
- `src/design-overrides.json`은 예전 편집 도구가 남긴 글꼴 덮어쓰기입니다. 지금 홈 구조와 선택자가 맞지 않아 사실상 적용되지 않습니다. 새 작업에 쓰지 마십시오.

### 로컬 실행

```bash
npm install
npm run dev        # http://localhost:3000
```

- Supabase 주소와 공개 키는 코드에 들어 있어 `.env` 없이도 운영 데이터로 화면이 뜹니다(`.env.example` 참고).
- ⚠️ **로컬에서도 운영 DB를 씁니다.** 화면 확인은 자유롭게 하되, **실제 주문 넣기·관리자에서 저장하기는 하지 마십시오.**
- 확인 명령: `npx tsc --noEmit`(타입 검사), `npm test`(테스트), `npm run build`(빌드).

### 배포 흐름

1. `main`에서 새 브랜치를 만들어 작업합니다.
2. GitHub에 푸시하면 Cloudflare가 브랜치별 **미리보기 주소**(`…workers.dev`)를 만들어 줍니다. 그 주소로 사장님께 확인받습니다.
3. PR을 만들고 사장님이 병합하면 **`main` 푸시 → Cloudflare가 자동으로 빌드·배포**합니다. 수동 배포 명령은 없습니다.
4. 디자인만 바꾸는 작업은 DB 변경이 필요 없습니다. 혹시 DB 변경이 필요하면 `supabase/migrations/`에 날짜 순 파일을 추가하고 Supabase SQL Editor에서 직접 실행해야 합니다(자동 적용 안 됨).

### 작업할 때 확인할 것

- 휴대폰 폭(360~390px)과 PC 둘 다 확인. 특히 주문 화면의 **아래 고정 막대**와 다른 요소가 겹치지 않는지.
- 버튼 높이 56px 이상, 본문 글자 15px 이상 유지.
- 글자와 바탕 대비가 충분한지(어르신 기준).
- 고객 화면 문구는 격식체.
